## نظرة عامة

**فاهم** منصة تعليمية إلكترونية متكاملة مبنية بـ Laravel 12. كل نسخة من المنصة مخصصة لمدرس واحد (نشر مستقل لكل عميل) — المدرس صاحب المنصة هو نفسه حساب **الأدمن**، ولو احتاج مساعدين (سكرتيرة، مسؤول محتوى...) بيضيفهم كحسابات أدمن إضافية بصلاحيات محدودة عن طريق نظام الأدوار. توفر المنصة محتوى مسجّل، حصص مباشرة عبر Zoom، نظام اختبارات متكامل، وبوابة متابعة لأولياء الأمور — كل ذلك مقسّم بشكل صارم بين **موقع أمامي** (طلاب وأولياء أمور) و**لوحة تحكم** (الأدمن/المدرس ومساعديه).

## المستخدمون والأدوار

يوجد ثلاثة أنواع مستخدمين في النظام (`users.type`): **admin** (صاحب المنصة والمساعدون)، **student**، **parent** (وليّ أمر)، مع نظام أدوار وصلاحيات دقيق فوقهم عبر [spatie/laravel-permission](https://github.com/spatie/laravel-permission).

الوصول بين الموقع ولوحة التحكم مفصول تمامًا عبر Middleware مخصص:

| Middleware | الوظيفة |
|---|---|
| `dashboard.access` | يمنع الطلاب وأولياء الأمور من الدخول إلى `/dashboard/*` ويعيدهم للموقع الأمامي |
| `front.access` | يمنع الأدمن من تصفح الموقع الأمامي ويعيده للوحة التحكم |

بمعنى: **الطالب** و**ولي الأمر** يستخدمان الموقع الأمامي فقط، و**الأدمن** (صاحب المنصة أو أي مساعد أضافه) يستخدم لوحة التحكم فقط — بدون تداخل بين الجلستين حتى لو كانتا بنفس المتصفح. تسجيل الدخول من نفس صفحة `/login` في الموقع: النظام بيجرب بيانات الدخول كطالب أولاً ثم كولي أمر، ويوجّه كل واحد لمكانه المناسب تلقائيًا.

## المميزات الرئيسية

### للطلاب (الموقع الأمامي)

#### التسجيل والدخول
- تسجيل حساب جديد واختيار المرحلة الدراسية
- تسجيل دخول آمن مع إدارة الجلسات

#### المسارات التعليمية
- ثلاث مراحل دراسية: **الإعدادي** / **الثانوي** / **البكالوريا**
- دعم مسار **عربي** ومسار **لغات**
- تصفح المراحل → الصفوف → المواد → الكورسات

#### الكورسات والمحتوى
- مشاهدة **دروس فيديو** (يوتيوب) منظمة داخل كل مادة، مع **تتبّع تلقائي لنسبة المشاهدة والاستكمال من نفس النقطة** التي توقف عندها الطالب في أي مرة سابقة
- تحميل **الملفات والمواد** المرفقة بكل درس
- صفحة "كورساتي" لمتابعة الاشتراكات النشطة
- إضافة الكورسات المفضلة لقائمة المفضلة
- نظام اشتراك بالفترات: **شهري / ترم 1 / ترم 2 / سنوي**
- الدفع عبر عدة وسائل (فودافون كاش، إنستاباي، وغيرها حسب إعدادات الإدارة) مع رفع لقطة شاشة إثبات الدفع

#### الاختبارات والتقييمات
- **كويزات** تفاعلية داخل الدروس مع مراجعة النتائج السابقة
- **تقييمات رسمية (Assessments)**: امتحانات/كويزات/واجبات بوقت محدد، درجات، وترتيب أسئلة، مسحوبة من بنك أسئلة مركزي
- صفحة "تقييماتي" لمتابعة كل النتائج السابقة

#### خدمات أخرى
- تقييم الكورسات (نجوم + تعليق) ومشاركة الرأي
- نموذج "تواصل معنا" للدعم الفني
- صفحات ثابتة: عن المنصة، الرؤية، فريق العمل، الشروط، الخصوصية، سياسة الاستخدام، الأسئلة الشائعة، الدعم الفني

---

### بوابة أولياء الأمور (الموقع الأمامي)

- حساب ولي الأمر بيتعمل من الأدمن بس (من لوحة التحكم)، مع ربطه بواحد أو أكتر من الأبناء (طلاب)
- ولي الأمر بيسجّل دخول من نفس صفحة `/login` العادية، وبيتوجّه تلقائيًا لبوابته الخاصة
- صفحة رئيسية بتعرض كل الأبناء المرتبطين بالحساب
- لكل ابن: المواد المشترك فيها، نتائج الامتحانات/الكويزات/الواجبات بالتفصيل، وحالة مشاهدة كل محاضرة (نسبة المشاهدة، مكتملة أو لأ، آخر مشاهدة)

---

### الحصص المباشرة — تكامل Zoom

- إنشاء حصص أونلاين مباشرة من داخل لوحة التحكم عبر **Zoom Server-to-Server OAuth API**
- ربط كل حصة بمرحلة/صف/مادة محددة
- إدارة رابط الاجتماع وكلمة المرور تلقائياً
- غرفة انتظار للطلاب قبل دخول المدرس، وكتم الميكروفون عند الدخول افتراضياً
- إمكانية تعديل وحذف الحصة من الداشبورد (مع مزامنة التعديل/الحذف على Zoom نفسه)

### لوحة تحكم الأدمن

#### إدارة المحتوى التعليمي

| القسم | الوظائف |
|---|---|
| المراحل الدراسية | إضافة / تعديل / حذف مراحل (إعدادي، ثانوي، بكالوريا) |
| الصفوف | إدارة الصفوف الدراسية لكل مرحلة |
| المواد | إنشاء مواد مرتبطة بمراحل وصفوف محددة، مع سعر وصورة غلاف |
| الدروس | رفع وإدارة دروس الفيديو داخل كل مادة، مع صفحة "👁 المشاهدات" لكل درس تعرض نسبة مشاهدة كل طالب مشترك في المادة |
| الملفات المرفقة | إضافة ملفات PDF وموارد تعليمية لكل درس |
| بنك الأسئلة | مكتبة أسئلة مركزية (اختيار من متعدد / صح وخطأ / مقالي) قابلة لإعادة الاستخدام عبر تقييمات متعددة، مصنّفة حسب المرحلة/الصف/المادة |
| التقييمات الرسمية | إنشاء اختبارات (امتحان/كويز/واجب) وربط أسئلتها من بنك الأسئلة مع تحديد الدرجة والترتيب |
| نتائج التقييمات | متابعة نتائج كل طالب في كل تقييم |

#### إدارة المستخدمين

- **الطلاب**: إضافة، تعديل، حذف، متابعة النشاط والنتائج
- **أولياء الأمور**: إضافة حساب لكل ولي أمر وربطه بأبنائه (طلاب) من قائمة اختيار متعددة
- **المشرفون (الأدمنز)**: إضافة أدمنز/مساعدين إضافيين (زي السكرتارية) بصلاحيات مختلفة عن طريق نظام الأدوار

#### نظام الصلاحيات (Roles & Permissions)

نظام صلاحيات دقيق (عرض / إضافة / تعديل / حذف) لكل قسم من الأقسام التالية بشكل مستقل: الأدوار، الأدمنز، الطلاب، أولياء الأمور، الإعدادات، المراحل، الصفوف، المواد، الدروس، الملفات، التقييمات، بنك الأسئلة، الاشتراكات، الكوبونات، الرسائل، طرق الدفع، تقييمات الكورسات، وقراءة نتائج التقييمات — مما يسمح بإنشاء أدوار مخصصة (سكرتيرة، إدارة محتوى، محاسب...) لكل منها صلاحياته الخاصة فقط، بدل ما يكون عندهم وصول كامل زي الأدمن الأساسي.

#### نظام الاشتراكات

- استقبال **طلبات الاشتراك** ومراجعتها من الداشبورد (قائمة الطلبات المعلّقة منفصلة)
- موافقة أو رفض الطلب بضغطة واحدة
- تتبع حالة الدفع (معلق / مدفوع / مرفوض)، وسيلة الدفع، رقم المرجع، ولقطة شاشة الإيصال
- نظام فترات (شهري / ترم 1 / ترم 2 / سنوي) لكل اشتراك مع تواريخ بداية ونهاية

#### نظام الكوبونات

- كوبونات **خصم نسبي (%)** أو **خصم ثابت**
- تحديد تاريخ بداية ونهاية صلاحية الكوبون
- تحديد الحد الأقصى لعدد مرات الاستخدام وحد أدنى لقيمة الطلب
- تفعيل وتعطيل الكوبون في أي وقت

#### الإدارة المالية

- **المدفوعات**: سجل شامل لكل عمليات الدفع في المنصة (فودافون كاش / إنستاباي)
- **المصروفات**: تسجيل مصروفات التشغيل ومتابعتها
- **طرق الدفع**: إضافة وإدارة وسائل الدفع المتاحة للطلاب (اسم الحساب، الرقم، ملاحظات)

#### تقارير ومتابعة

- نتائج الكويزات والتقييمات الرسمية لكل طالب بالتفصيل
- تقييمات الطلاب للكورسات
- رسائل "تواصل معنا" مع إمكانية العرض والحذف

#### إدارة المحتوى الثابت والإعدادات

- تعديل محتوى الصفحات الثابتة من الداشبورد مباشرة (عن المنصة، الرؤية، فريق العمل، الشروط، الخصوصية، سياسة الاستخدام، الأسئلة الشائعة)
- إعدادات عامة للموقع: الاسم، الشعار، بيانات التواصل، أرقام فودافون كاش/إنستاباي، روابط السوشيال ميديا

#### أدوات النظام

- **تصدير قاعدة البيانات**: صفحة لعرض حجم/عدد صفوف كل جدول، وتحميل نسخة احتياطية كاملة (`.sql`) لقاعدة البيانات بضغطة واحدة

## التقنيات المستخدمة

- **Backend**: Laravel 12 / PHP 8.2+
- **Frontend**: Blade Templates + Bootstrap 5 RTL + Tailwind CSS 4 (عبر Vite) + jQuery + Select2 + Chart.js

- **Build Tool**: Vite 7

## هيكل المشروع (أهم النقاط)

```
routes/web.php         → روابط الموقع الأمامي (طلاب + أولياء أمور) — كل الروابط تحت middleware "front.access"
routes/dashboard.php   → روابط لوحة التحكم (أدمن) — تحت "auth" + "dashboard.access"

app/Http/Controllers/Front/       → كنترولرات الموقع الأمامي (بما فيها ParentPortalController)
app/Http/Controllers/Dashboard/   → كنترولرات لوحة التحكم

app/Http/Middleware/DashboardAccess.php → يمنع الطلاب/أولياء الأمور من دخول اللوحة
app/Http/Middleware/FrontAccess.php     → يمنع الأدمن من دخول الموقع

app/Services/ZoomService.php              → التكامل مع Zoom API
app/Services/AssessmentQuestionService.php → منطق ربط الأسئلة بالتقييمات

app/Models/  → كل الكيانات: User, Subject, Grade, Stage, Lecture, Material,
               Subscription, Coupon, OnlineMeeting, LectureProgress,
               Contact, PaymentMethod, CourseReview, Assessment, AssessmentResult,
               QuestionBankQuestion, QuestionCategory, Expense, Favorite, وغيرها
```

> ملاحظة: يوجد نظام كويزات قديم (`Quize` / `Question` / `QuizResult`) مرتبط بالدروس مباشرة، بجانب نظام التقييمات الرسمية الأحدث (`Assessment` + بنك الأسئلة) وهو النظام الأساسي الحالي للاختبارات.

## تشغيل المشروع

```bash
# تثبيت الحزم
composer install
npm install

# إعداد البيئة
cp .env.example .env
php artisan key:generate

# تهيئة قاعدة البيانات
php artisan migrate --seed

# تشغيل السيرفر + الـ Queue + الـ Vite dev server معاً
composer dev

# أو تشغيل كل واحدة على حدة
php artisan serve
npm run dev

# لبيئة الإنتاج: بناء الـ Assets
npm run build
```

### متغيرات البيئة (`.env`)

أهم المتغيرات المطلوب ضبطها (بعضها غير موجود في `.env.example` ولازم يتضاف يدويًا):

```env
APP_NAME=فاهم
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=fahem
DB_USERNAME=root
DB_PASSWORD=

# بيانات تطبيق Zoom (Server-to-Server OAuth) — غير موجودة في .env.example، لازم تُضاف يدويًا
ZOOM_ACCOUNT_ID=your_account_id
ZOOM_CLIENT_ID=your_client_id
ZOOM_CLIENT_SECRET=your_client_secret
ZOOM_BASE_URL=https://api.zoom.us/v2
```

بيانات Zoom لازم يكون عندها الصلاحيات (Scopes) التالية على الأقل من [Zoom Marketplace](https://marketplace.zoom.us): إنشاء وتحديث وحذف الاجتماعات (`meeting:write:meeting:admin`, `meeting:update:meeting:admin`, `meeting:delete:meeting:admin`).

## النشر (Deployment)

يوجد GitHub Actions workflow (`.github/workflows/main.yml`) يقوم بالنشر التلقائي عبر SSH عند كل `push`، وينفّذ `composer install`، `php artisan migrate --force`، ثم تنظيف الكاش (`config:clear`, `route:clear`, `view:clear`, `cache:clear`). تأكد من ضبط أسرار الاتصال (host/user/key) في إعدادات الـ Repository قبل الاعتماد عليه، ومن مطابقة السيرفر المستهدف للبيئة الفعلية اللي بتستخدمها.

بما إن المنصة بقت نسخة منفصلة لكل مدرس، أي نشر جديد لمدرس تاني لازم يكون على نسخة منفصلة تمامًا (سيرفر/قاعدة بيانات خاصة بيه) — مفيش تعدد مستأجرين (multi-tenancy) داخل نفس التثبيت.
